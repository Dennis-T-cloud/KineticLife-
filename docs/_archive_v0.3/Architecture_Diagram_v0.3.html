2Body-Pose Gestures (new in v0.3)

Synthesized from the existing 33 Pose keypoints. No Hand Landmarker (extra CPU not worth it).

GestureDefinitionTrigger
Both hands overhead (1.5s)Both wrist.y < nose.yStart / confirm
Arms crossed in front (1.5s)Wrists cross to opposite shoulder, y ~chestEnd current set
One hand overheadOne-sided wrist.y < nose.yPause / resume
T-Pose (2s)Wrists level with shoulders, spread > 1.5× shoulder widthCalibrate / reset
Point at camera (1s)wrist.z - shoulder.z < εCycle display

Demo Day moment: presenter raises hands → system starts; crosses arms → system ends. Zero-touch. Expected >98% accuracy, <2% false triggers.
